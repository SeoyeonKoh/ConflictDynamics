# Pydantic / Hydra 전환

- 타입·범위·빈 문자열·알 수 없는 필드는 Pydantic v2가 검증한다.
  strict 모드로 기존의 문자열/불리언 숫자 변환 거부를 유지한다.
- `Thread`는 가변 dataclass로 유지하고 트리의 관계 규칙만 직접 검사한다.
- Hydra 표준 `@hydra.main`을 사용한다. CLI는 `rule=bidding`과 `-m` 문법으로 바뀐다.
- 기본 설정과 합성 시드를 패키지 안으로 옮겨 wheel 설치 후에도 기본 실행이 가능하게 한다.
- 시드 상대 경로는 선택한 주 설정 파일의 디렉터리를 기준으로 해석한다.
- Hydra가 실행 폴더와 `.hydra` 메타데이터를 관리한다. 시뮬레이터는 그 안의
  `corpus/`에 기존 형식으로 저장하고 기존 corpus를 덮어쓰지 않는다.
- 기존 runs 데이터는 수정하지 않는다. 이전 설정 내용은 `--config-path`로 사용할 수 있고,
  이동한 시드 경로는 기존 실행의 `seed.json` 사본으로 지정할 수 있다.

검증 순서: 기존 65개 테스트 → 엄격한 입력 검증/설정 합성/CLI override/multirun 테스트 추가
→ 구현 → 전체 테스트·Ruff·wheel 설치 및 기본 실행 확인.

완료: 테스트 79개, Ruff 검사, sdist/wheel 빌드 통과. 프로젝트 밖의 별도 wheel 설치
환경에서도 기본 데모가 발화 2개를 생성하고 4틱 후 침묵 종료했다.
설정 그룹 합성, 보간, 6개 조건 멀티런, 중첩 config-name 및 config-dir 선택,
Hydra 작업 디렉터리 변경 시 시드 경로 보존을 검증했다.
